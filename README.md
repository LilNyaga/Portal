# PhysioConnect – KMTC Nyeri Campus

Unified Platform for Physiotherapy Department Communication & Resource Access.

## Technologies Used

- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Lucide Icons
- **Backend & Cloud Services:** Firebase (Authentication, Cloud Firestore and Firebase Storage)
- **Bundler:** Vite

## How to Run in VS Code

1. Open the project folder in VS Code.
2. Open the integrated terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite, usually `http://localhost:5173`.

## Features Implemented

### 1. Navigation Drawer

- **Finance Sector:** Fee statement balance, M-Pesa Paybill instructions and invoice ledger.
- **Exams & Academic Records:** Cumulative GPA, supplementary checker and semester-by-semester grade breakdown.
- **Hostel Accommodation:** Booking portal and room allocation.
- **Revision Archive:** Past examination papers repository.
- **Staff Directory:** Contact information for HOD, lecturers and class representatives.

### 2. Main Dashboard

- **Active Semester Status:** Displays current semester registration.
- **Class & Cohort Identity:** Displays class and admission information.
- **Urgent Broadcast Notices:** Clinical attachment announcements with acknowledgment actions.
- **Today's Timetable:** Displays current and upcoming classes.
- **Direct Action Tiles:** Shortcuts to Exams, Fees, Hostels and Revision.
